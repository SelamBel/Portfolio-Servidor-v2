# PHP School Project

## Overview
This is a PHP development environment set up for school project work. It runs entirely in the browser through Replit, requiring no local installation.

## Project Information
- **Language**: PHP 8.4
- **Server**: PHP Built-in Development Server
- **Port**: 5000
- **Created**: November 01, 2025

## Project Structure
```
.
├── index.php          # Main entry point
├── .gitignore         # Git ignore rules
└── replit.md          # This file
```

## Getting Started
1. Edit `index.php` or create new PHP files
2. The server automatically reloads when you save changes
3. View your application in the webview panel

## Features
- PHP 8.4 runtime environment
- Built-in web server
- Automatic reload on file changes
- No local installation required
- Accessible from anywhere with internet
